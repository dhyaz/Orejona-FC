# Orejona FC

Plantilla HTML (un solo archivo) para crear gráficos de fútbol en PNG transparente de 1080×1920:

- **Alineación (VS)**
- **Marcador** (goleadores y eventos)
- **Titulares** (titular con micrófono)

## Uso

Abre `OrejonaFC-titulares.html` en el navegador (Chrome recomendado). No necesita instalación ni conexión.
